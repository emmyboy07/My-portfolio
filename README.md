# My Portfolio

A responsive student portfolio and academic management website — built for COS 106 (Introduction to Web Technologies) at MIVA Open University.

**Live site:** https://emmyboy07.github.io/My-portfolio/

## Pages

- **Home** — intro, photo, and a quick snapshot of what I'm working on
- **About Me** — education, career goals, technical skills, hobbies, and an audio sample
- **Projects** — BizPilot, Sonix Hub, and VibeSync
- **Academic Planner** — add, complete, and delete tasks, saved locally in the browser
- **Contact** — a form with client-side validation (required fields, email format, digits-only phone)

## Built With

- HTML5 (semantic markup, forms, tables, lists, multimedia)
- CSS3 (Flexbox, Grid, responsive layout, transitions)
- Vanilla JavaScript (DOM manipulation, event handling, localStorage)

## Running Locally

Clone the repo and open `index.html` in a browser, or serve it with any static server:

```
git clone https://github.com/emmyboy07/My-portfolio.git
cd My-portfolio
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
